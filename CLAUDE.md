## What this service is

SpyneRealmSDK is the iOS, macOS, tvOS, and watchOS implementation of Realm Database—a mobile object database that runs directly on Apple devices. It provides Swift and Objective-C bindings for developers to persist, query, and observe data locally without requiring a server or ORM.

## Architecture

This is a compiled framework distribution containing Swift and Objective-C language bindings atop a C++ core library (realm-core v20.1.5). The Swift layer (RealmSwift/) wraps Objective-C interfaces (Realm/), which in turn call the precompiled C++ core via XCFramework bundles. Build artifacts are produced as xcframework files for distribution via CocoaPods, Carthage, or Swift Package Manager. The repository includes example apps, integration tests, and build automation scripts.

## Before you change this

- Thread confinement: Realm instances are thread-local and cannot be shared across threads without explicit queue assignment; violations raise exceptions. Developers must obtain a new Realm instance per thread or confine to a DispatchQueue.
- Encryption key management: Applications must securely generate and store encryption keys (e.g., using SecRandomCopyBytes) if using encrypted Realms; key loss means data is unrecoverable.
- Schema migration: Changes to Object definitions (adding/removing/renaming properties) require migration logic; missing migrations cause crashes on version mismatch.
- Write transaction blocking: Write transactions are synchronous and can block the UI thread if executed on the main thread; large transactions should use async APIs or background queues.
- Memory overhead: Live objects maintain observer subscriptions in memory; developers must unsubscribe (set token to nil) to prevent memory leaks.
- Realm file locking: Multiple processes writing to the same Realm file concurrently will cause crashes; only one writer per file is allowed.
- SwiftUI observation timing: @ObservedResults may trigger view redraws even for unrelated property changes; use fine-grained filters to optimize performance.
- Core binary dependency: SDK functionality depends on precompiled realm-core C++ library; mismatched versions between framework and app can cause runtime errors.
